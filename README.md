# 1. 프로젝트 소개
Grids & Circles는 작은 로컬 카페에서 운영하는 온라인 커피 원두 패키지 주문 서비스입니다.

고객은 웹사이트를 통해 손쉽게 원하는 원두 패키지를 주문할 수 있으며, 매일 전날 오후 2시부터 당일 오후 2시까지 접수된 주문을 모아 일괄 처리합니다.

현재 제공되는 상품은 총 4종류의 원두 패키지로, 다양한 취향에 맞게 선택할 수 있습니다.
